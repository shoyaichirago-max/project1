Tentang Saya

Halo! Perkenalkan, nama lengkap saya adalah Hervi Andri Maulana, dan saya biasa dipanggil Andrian. Saat ini saya adalah seorang pelajar yang duduk di bangku kelas X RPL 1 (Rekayasa Perangkat Lunak) di jurusan RPL.

Saya tinggal di Provinsi Jawa Timur, Kabupaten Jember, Kecamatan Semboro, tepatnya di Jalan Manggis. Sejak kecil, saya memiliki rasa ingin tahu yang tinggi terhadap cara kerja berbagai perangkat teknologi yang ada di sekitar saya. Hobi saya meliputi bermain game, olahraga, bermain alat musik, dan menonton film. Beragam hobi ini mengajarkan saya tentang kreativitas, fokus, dan kerja keras.

Sebagai seorang pelajar, saya selalu berusaha untuk terus belajar hal-hal baru, mengembangkan kemampuan diri, dan mempersiapkan masa depan yang cerah di era digital ini.

Alasan Minat Memasuki Bidang IT

Dunia Teknologi Informasi (IT) bukanlah sekadar pilihan jurusan bagi saya, melainkan sebuah passion dan tujuan hidup. Berikut adalah beberapa alasan utama mengapa saya sangat berminat untuk memasuki dan berkarier di bidang IT:

  • 1. Perkembangan Teknologi yang Sangat Pesat: Kita hidup di era di mana hampir semua aspek kehidupan digerakkan oleh teknologi. Mulai dari komunikasi, pendidikan, kesehatan, hingga bisnis semuanya membutuhkan sistem berbasis komputer. Saya ingin menjadi bagian dari orang-orang yang menciptakan teknologi tersebut, bukan hanya sebagai pengguna.
  • 2. Kecintaan pada Pemrograman dan Problem Solving: Menulis kode program bagi saya seperti menyusun puzzle. Ada kepuasan tersendiri ketika berhasil memecahkan masalah logika atau menemukan bug dalam sebuah kode dan memperbaikinya. Jurusan RPL memberikan saya wadah yang tepat untuk mengasah kemampuan berpikir logis ini.
  • 3. Peluang Karier yang Luas dan Menjanjikan: Bidang IT menawarkan peluang kerja yang sangat luas, baik di dalam negeri maupun di tingkat global. Profesi seperti Software Engineer, Web Developer, Data Analyst, hingga Cyber Security Expert sangat dibutuhkan saat ini dan di masa depan.
  • 4. Kebebasan Berkreasi dan Inovasi: Dengan kemampuan IT, saya bisa membangun apa saja dari nol, mulai dari website sederhana, aplikasi mobile, hingga game. Hal ini memungkinkan saya untuk mewujudkan ide-ide kreatif menjadi produk nyata yang bermanfaat bagi banyak orang.
  • 5. Memberikan Dampak Positif bagi Lingkungan Sekitar: Saya bercita-cita suatu saat nanti dapat membuat aplikasi atau sistem informasi yang bisa membantu masyarakat di daerah saya, Jember, agar lebih mudah mengakses informasi dan layanan publik secara digital.

Keterampilan yang Sedang Dipelajari

Selama menempuh pendidikan di jurusan Rekayasa Perangkat Lunak (RPL), saya telah dan sedang mempelajari beberapa keterampilan dasar yang menjadi fondasi di dunia IT:

HTML dan CSS

Membangun struktur dan tampilan halaman website yang responsif dan menarik.

Logika Pemrograman

Memahami algoritma dasar dan cara berpikir komputasional untuk menyelesaikan masalah.

Penggunaan Tools

Terbiasa menggunakan Code Editor seperti VS Code dan memahami manajemen file proyek.

Kerja Sama Tim

Berkolaborasi dengan teman sekelas dalam mengerjakan tugas-tugas proyek pemrograman.
